# TalkMoves baseline artifacts

The fitted TF-IDF / logistic-regression pipeline and human-label classroom reference
rates are derived from the **TalkMoves** corpus by Suresh et al. (2022),
“The TalkMoves Dataset: K-12 Mathematics Lesson Transcripts Annotated for Teacher
and Student Discursive Moves,” LREC 2022, pp. 4654–4662.
Paper: https://aclanthology.org/2022.lrec-1.497/

Source: https://github.com/SumnerLab/TalkMoves
Pinned revision: `869b9406de268ebab0f1b9a3bccde0b416b97290`.

The source corpus is licensed **CC BY-NC-SA 4.0**. These derived artifacts are
distributed under the same attribution, noncommercial, and share-alike terms.
See the accompanying `LICENSE.txt`. This is not a commercially permissive dataset.
Raw transcript sentences are not included in the repository. The fitted vocabulary
can nevertheless retain corpus tokens, so these artifacts still require the stated
attribution and license restrictions.

`talkmoves.joblib` is a trusted local artifact generated by
`data/scripts/train_talkmoves.py` with scikit-learn 1.7.2 and joblib 1.5.2.
Joblib/pickle deserialization can execute code: never replace it with an untrusted
download or accept uploaded joblib files. Artifact checksum and size are recorded
in `talkmoves_metrics.json`; reproduction details and quality checks are in
`data/results/metrics.json` and `data/results/benchmark_summary.json`.

The seven-class model describes discourse moves rather than teaching quality.
References cover K-12 mathematics lessons and are descriptive, not causal targets
for college presentations. Upstream model context is a preceding student utterance;
live FrontRow supplies a preceding presenter sentence, which is a distribution shift.
